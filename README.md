# tweaks

[English](README.en.md)

> [!NOTE]
> この Mod は [Steam 版『侍道4』](https://store.steampowered.com/app/312780/4/?l=japanese)専用です。

「あったらいいな」と思う小さな調整（Tweak）を集めた Mod です。それぞれの調整は、ゲームのオプションに追加される「Tweaks」のページで、個別に切り替えられます。

## 機能

- **ローラの夜這い**：ローラと夜這いを約束したとき、布団の中で待つ相手を固定できます。
  - 固定しない：ゲームのままです。約束してからゲームを起動し直したかどうかなどで、どちらになるかが変わります。
  - 偽物：布団をめくると、ローラに化けた別人に入れ替わります。
  - 本物：ローラ本人と夜這いをします。
- **漁り確定ドロップ**：死体を漁ったり蹴ったりしたとき、その体が出せる物を持っていれば、1 回目で必ずアイテムが出ます。どのアイテムが出るかの割合はゲームのままです。町の人が死んだときに自分で落とすアイテムは変わりません。
- **俺流上限突破**：俺流を作るとき、腕前点が足りなくても技を好きなだけ入れられます。画面の「合計／腕前点」の表示はそのままなので、合計が腕前点を超えて見えます。腕前点は減りません。
- **なりわい即完了**：なりわいを受けると、会話が終わったところですぐに成功します。報酬・治安・記録はふつうに成功したときと同じです（倒した数などによる追加の報酬は入りません）。昼に受けた夜のなりわいも、すぐに成功します。
  - 野戸仏・小鳩・泥棒さん・おっつぁん・汁部の続き物のなりわい、「賭場を偵察せよ」「代官所を偵察せよ」などの戦いのなりわい、最後の「阿弥浜八人衆」も対象です。依頼主の次の依頼は、ふつうに成功したときと同じように出ます。
  - 標的との戦いや会話の場面は見られません。「おじいさんの想い出」「くさい物にふた」は、前編を受けると後編も続けて受け、どちらも成功します。
- **口説き確定成功**：口説いたとき、質問にどう答えても必ず夜の約束を交わせます。夜杯流体術で名のある人物（赤城・小暮・琴吹・茂呂・鬼怒川・J.J・堂島）を口説いたときも、段に関係なく 1 回で約束を交わせます。もともと口説けない人や、今夜の相手がすでに決まっているときは、今までどおり断られます。
- **鍛冶結果最高**：鍛冶屋で「強くしたい」と精錬・鋳直しを頼んだとき、攻撃力の上がり幅がいつも最大になります（堂島の鍛冶屋の上乗せも最大です）。「硬くしたい」「磨いてほしい」はもともと決まった値なので変わりません。
- **弟子確定成功**：「弟子にしてやる」と誘うと、必ず弟子になります。道場がない・閉鎖されている・満員（20 人）のときは、今までどおり断られます。

## インストール

> [!WARNING]
> 事前に [wots4-mods（ModLoader）](https://github.com/nagataaaas/wots4-mods) を導入してください。

1. ゲームを終了してください。
2. [Releases](../../releases) から `wots4-mod-tweaks-<バージョン>.zip` をダウンロードし、解凍してください。
3. 解凍して得られた `mods` フォルダを、侍道4のインストールフォルダ（`WayOfTheSamurai4.exe` がある場所）へコピーしてください。すでに `mods` フォルダがある場合は、その中にまとめてください。
4. `{侍道4インストールフォルダ}/mods/tweaks/mod.dll` があることを確認し、ゲームを起動してください。

## 設定

タイトル画面のオプション、またはポーズメニューの「各種設定」に追加される「Tweaks」のページで切り替えてください。項目が 8 個を超えると、ページの中を上下にスクロールできます。

変えた設定は、ゲームがオプションを保存したときに `{侍道4インストールフォルダ}/mods/tweaks/config.ini` に保存され、次に起動したときも引き継がれます。
